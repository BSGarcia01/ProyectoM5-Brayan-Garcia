# Servidor MCP para GitHub

Proyecto integrador del módulo 5 de Soy Henry.

El objetivo es desarrollar un servidor MCP con Node.js y TypeScript
que permita a un agente de IA ejecutar operaciones en GitHub mediante
instrucciones en lenguaje natural.

## Herramientas previstas

- create_repository
- create_issue
- list_repositories
- create_commit
- list_issues
